Read a lab in the browser, or run it live — no local install needed.

Every lab has three options:

  • Read lab — the notebook rendered as a static HTML page (read-only, instant).
  • Download notebook — the raw notebook to download or open in your own Jupyter.
  • Run in Colab — the zero-setup way to run a lab. Just run the first cell (Running on Google Colab?): it clones the repo, installs requirements-labs.txt, and switches into labs/ so relkit and the data cache work. The CHECK/EXIT cells then run exactly as they do locally, and a free T4 GPU is available under Runtime → Change runtime type for the labs that want one.
