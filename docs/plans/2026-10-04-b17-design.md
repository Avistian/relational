## Frozen course experiment: B17-REPRESENTATION-BOUNDARY

Three initialization seeds 0/1/2, float64 CPU, two encoder blocks and two decoder blocks, width16, one attention head, feed-forward width32, no dropout or optimization. Four numeric feature rows in support and two query rows, two columns; support [[-1,0],[0,1],[1,0],[0,-1]], query [[.5,.5],[-.5,-.5]]. Fixed identifiers s0..s3,q0..q1. Task A support labels [0,0,1,1], task B [0,1,0,1]. Query labels for reporting only: A [1,0], B [1,0]. These deliberately specified examples test dependencies, not learned performance or accuracy. No data or initialization selection.

Target-free encoder: linear scalar tokenization with column embeddings, [ROW] token, cross-column attention to feature tokens only, cross-row attention to support rows only, residual/normalization/feed-forward blocks; separate projection of each layer's row outputs, sum, final projection. Decoder: binary support label embedding, query mask, row embedding cross-attention, support-only target-stream attention, feed-forward and binary head. This reduced numerical mirror omits the paper's semantic/categorical/time tokenizers, multihead depth/width, all training and specialized decoders. It is not authenticated released-source parity.

For each seed and task run baseline, complement support labels, swap one support feature, change only the other query feature, permute support features/labels/IDs together, and permute query rows. Check target exclusion by changing externally held query labels without passing them into inference. Reuse cached embeddings on label-only edits; require a miss on support feature, row order, model state or preprocessing identity edits. Match fresh and cached predictions. Record arrays, fingerprints, state tensors, IDs and per-seed deltas. No hyperparameter search. Float64 tolerance1e-10 for independent forward comparisons. Labels change predictions but not embeddings; support changes may change both; another query must not affect q0.
