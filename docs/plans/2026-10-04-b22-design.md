## Frozen B22-SUPPORT-WRITE course experiment
Three fixed random-weight seeds 0,1,2; no training. The same 24 episodes for each model: linear, XOR and radial rules, eight replicates each, generator seeds 22000..22023. Each episode has 12 balanced support rows and 16 balanced query rows, two features, two classes. Coordinates drawn uniformly on [-1,1]^2 using rejection sampling per class. Rules: x0>0; x0*x1>0; squared radius>0.5. Queries are independent draws. These are course choices, not the paper's RBF episodes.

Course architecture: two-feature projection to width8, support-only binary label embedding; three single-head attention-gated residual blocks. Every row reads only support keys/values (including support self-reads); layer normalization eps1e-5, scaled dot-product softmax, normalized attention read multiplied by a SiLU state gate, output projection and residual addition. Final linear binary classifier. All weights from NumPy PCG64, float64, fixed normal scale0.25. No feature-interaction module, RowCLS compression, typed memory or pretraining. Explicitly explain these omissions beside the complete paper architecture.

Four arms on every model/episode: normal; identity replacement; skip second-block support write (restore its input support states); permute second-block support updates (fixed one-row cyclic rotation, add to their original inputs). The intervention occurs after the second block; preserve its query outputs exactly; run the third block normally. Permuting updates preserves their multiset, but is a course extension, not the paper's Table10 scoring-only counterfactual. Query labels enter scoring only. Record all 288 trajectories, 4608 query predictions, all intermediate states, weights, data, permutations and metrics. Report all 72 paired effects per arm and per-model means/ranges.
