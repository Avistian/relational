Recap: the residual block you are about to train

The ResNet is nothing exotic — it is an MLP whose blocks add a skip connection. Each block computes a small correction f(x) and returns x + f(x) rather than f(x). Here is one block; toggle the skip off to see the plain-MLP block it reverts to.

One residual block, the Gorishniy 2021 §3.2 form: x + Dropout(Linear(Dropout(ReLU(Linear(BatchNorm(x)))))). The six operations in the branch f(x) are identical either way; the single line that turns a plain MLP block into a ResNet block is the skip.

Skip (residual) connection. The wire that carries the block's input x around its transformation and adds it back: output = x + f(x). Because the branch f can settle near zero, the block can act as the identity for free — so stacking more blocks can never make the network strictly worse. Removing it (output = f(x)) forces every added block to re-learn an approximate identity, which is hard. (First built in L028.)
BatchNorm. A layer that normalises each activation across the current mini-batch (subtract the batch mean, divide by the batch std, then apply a learned scale and shift). It keeps the scale of activations stable as they flow through many layers, which is what makes deep stacks trainable without exploding or vanishing values. Both the plain net and the ResNet below use it — so any difference between them is the skip, not normalisation.

Why the skip is not optional: the degradation problem

You might expect a deeper plain MLP to be at least as good as a shallow one — worst case, the extra layers learn to pass their input through unchanged. In practice they do not. Below is the same architecture trained at growing depth with the skip on (ResNet) vs off (plain MLP); the numbers are the verified run from L028's lab.

Test accuracy vs depth. Adding blocks hurts the plain MLP (0.917 → 0.866) but leaves the ResNet flat (0.912 → 0.899). Toggle the training curves: the plain net's training accuracy also falls (1.000 → 0.927), so it cannot even fit the data — this is an optimization failure, not overfitting.

Degradation problem (He et al. 2015). A deeper plain network reaches a higher training error than a shallower one — the optimizer cannot find the identity-preserving solution that would make depth harmless. The residual skip fixes it by making that identity solution free (set f ≈ 0), which is the entire reason ResNets exist. Because both nets here use BatchNorm, this is not vanishing gradients; it is the optimizer failing to fit.

The shared tuning protocol — what "trained fairly" means

Training a ResNet well is not the hard part; training it comparably is. Gorishniy 2021's real contribution is a shared protocol: one fixed recipe applied identically to every model, so that a difference in scores is a difference in models, not in effort. It is L017's fair-budget rule and L038's HP-budget parity, promoted to a field standard. The recipe has two halves — a shared frame and a per-model search space.

Shared frame (identical for every model). The same train/validation/test split (L020 contract), the same evaluation metric, the same hyper-parameter search budget (number of trials), and selection by validation score with the test set touched once. Change any of these between two models and "A beat B" may just mean "A got more trials" or "A was scored on an easier split."
Per-model search space. The knobs each model is allowed to vary, drawn from the same budget. For the ResNet: number of blocks, main width d_main, hidden width d_hidden, the two dropout rates, learning rate, and weight decay. Different models have different knobs — that is fine; what must match is the budget spent searching them.

Two training-recipe terms the neural baselines rely on, defined before we use them:

AdamW & weight decay. Adam is the standard optimiser for these nets: it adapts a per-parameter step size from running estimates of the gradient's mean and variance, which makes deep nets train reliably without hand-tuning a single global learning rate. Weight decay gently shrinks the weights toward zero each step (an L2-style regulariser that fights overfitting); AdamW is the variant that applies it correctly, decoupled from the adaptive step. Learning rate and weight decay are two of the ResNet's search knobs.
Early stopping. Train for many epochs but keep the weights from the epoch with the best validation metric, and stop once validation stops improving for a set patience. It is how a neural baseline picks its own training length fairly — the analogue of a GBDT's early-stopped n_estimators — so neither model is under- or over-trained by accident.
Build it yourself; let the library check you. You learn a model by implementing it — the residual block you wrote in L028 is the ResNet used here (now in relkit.nets), not a black box you imported. A reference library — here rtdl, Gorishniy's own implementation — is used as a validation point: train your version and the reference under the identical protocol and confirm they land within noise of each other. A from-scratch model can hide a silent bug or be quietly under-powered (the weak-baseline trap again); the reference is the checker that catches it. The lab does exactly this.

The rule: run the strong simple baselines first

Put the frame and the recipe together and you get Gorishniy 2021's practical instruction. Before you trust a TabNet, a NODE, or a transformer, you run the tuned MLP and ResNet first, under the same protocol. The paper's sting is that a tuned ResNet alone matches a large fraction of published "novel" architectures — so a new model that fails to beat it has demonstrated nothing, no matter how clever its mechanism.

Baseline-first rule ("do these first"). The strong simple baselines (tuned MLP + ResNet) are computed before the fancy model, to the same protocol, and reported alongside it. Skipping them — or comparing only against a GBDT, or against an untuned MLP — is the exact failure mode that made the pre-2021 literature unreliable. Beating a weak baseline is a tuning-effort gap wearing a model-quality mask (L038).

Why one dataset is not evidence — the cross-dataset view

A comparison on a single table is a demonstration, never proof — the winner can change with the dataset, so a claim like "no universal winner" is a statement about datasets and can only be read across many. So we ran the identical protocol on four small real tables and summarised with mean ranks (1 = best per dataset), the field-standard cross-dataset method (L023, L030).

…but read it honestly: a small, biased sample is not the verdict. Taken at face value this says "the tuned nets significantly beat the GBDT" — which would contradict the well-established result that trees usually win on tabular data. The catch is the sample: four tables, three of them all-numeric — exactly the regime Grinsztajn 2022 shows favours neural nets. A tiny, non-representative set can produce a "significant" p that does not generalise. This is itself the rigor lesson: which datasets you pick decides the answer, so the conclusion must come from a large, varied benchmark — not four tables of our choosing, and certainly not one.
No universal winner — the version that actually holds. The authoritative cross-dataset verdict is Grinsztajn 2022's ~45-dataset study (and Gorishniy 2021): no single model dominates, with tree ensembles typically ahead on categorical/irregular tables and neural nets competitive-to-ahead on large, numeric ones. What we verified here on four tables is the honest, narrow claim — a fair, from-scratch neural baseline is genuinely strong, so any fancier model has a real bar to clear — plus the method (per-dataset CIs + mean ranks + a Friedman/critical-difference read). The strong claim is cited to the big benchmark; our small run is a demonstration of how you'd earn it.

Thesis bridge

Why train these before touching a transformer. The mission's claim is comparative: a relational model that keeps the structure a flatten destroys beats the fair single-table bar. That bar is now two-sided — a tuned GBDT (Year 1) and a tuned MLP/ResNet (today). A skeptic's easiest dismissal of an eventual RDL win is "you only beat trees; a good neural net would have won on a flat table too." Training the neural baselines correctly, first, forecloses that move. And the machinery is the same you will reuse: an RDL model is an encoder → message passing → a residual-MLP head, so the block you train today is a component of the relational model you build in Years 3–5.
