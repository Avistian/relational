### Read the forks before the arrows merge

One edge does two jobs. Its key meets the receiver's query to produce a scalar compatibility score per head. Its value becomes a vector message per head. Relation matrices affect both jobs through separate parameter banks. Multiplying a message by an attention weight joins the branches; the scalar alone is not the message. Read [HGT §3.2–3.4](https://arxiv.org/html/2003.01332v1) with that separation in view.

Suppose two edges receive weights .9 and .1, but their scalar message coordinates are 1 and 20. Their contributions are .9 and 2. The edge with smaller attention supplies the larger positive coordinate. If the second value were −20, its contribution would oppose the first. Thus a displayed attention heatmap is not a decomposition of predictive importance. Output projection, residual mixing and later layers further change the result.

### Trace the parameter-sharing decision

Consider `(author,writes,paper)` and `(author,reviews,paper)`. Both use the author-type key/value projections and paper-type query projection. Different relation transforms still distinguish writing from reviewing. Now consider `(paper,cites,paper)`: the target query map is still the paper map, while the sender key/value map changes to the paper map. Write down those shared and changed pieces before counting parameters.

This factorization is a modeling bias: it lets multiple connections reuse type-level transformations. It is not permission to merge distinct foreign-key roles into an ambiguous relation name. The data representation must preserve the role before a learned layer can use it. L096 will make that identity contract executable.

### Cross-relation normalization is part of the architecture

At one receiver/head, collect every eligible incoming score and take one softmax. A new candidate can change every existing normalized weight even if their raw scores remain fixed. With scores `[0,ln 2]`, weights are `[1/3,2/3]`. Add an edge with score zero and they become `[1/4,1/2,1/4]`. If all three message values equal 5, the aggregate stays 5. Changing weights therefore need not change the message; changing the message need not identify which score caused it.

This observation connects sampling to modeling. Dropping one competitor changes a softmax denominator. Finite-fanout attention is not merely a cheaper way to write the same full-neighborhood formula. L098 isolates this difference before L100 integrates it into the comparison.

### Finish the layer, then choose the task

The released operator concatenates head outputs, transforms them, and blends the result with the previous state. With a scalar teaching gate of .75, old state 2 and candidate 6, the mixture before normalization is 5. Omitting the residual would give 6. Equal attention coefficients cannot establish equality of two layers that have different value maps or residual paths. The [pinned release](https://github.com/acbull/pyHGT/blob/85eaccd482bc1d1af56c2de297b6e3a88b96d5cd/OAG/pyHGT/conv.py) is essential here because its gated update differs from the paper's printed additive residual.

The output task determines the final head and loss. The paper-field reconstruction predicts a distribution over fields; the later course ACM comparison predicts one conference class. Sharing an HGT operator does not make these the same experiment.
