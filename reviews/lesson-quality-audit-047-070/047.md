## Local derivations and teaching repairs

These are derived explanations, not extra empirical paper claims:

- LayerNorm is defined with population variance over the normalized coordinates and epsilon. The x=[1,3], F(a)=2a example produces different values for released, PDF, and conventional pre-normalized residuals, despite matching shapes.
- GEGLU row feed-forward parameter count is derived as `12(Td)^2+9Td`, giving 93,720 at T=11,d=8. Batch-square attention storage is distinguished from width-square parameters.
- Singleton attention has weight1 but retains value/output projections, normalization, and FF. Row-only dense mixing can transfer feature information to CLS. Singleton evaluation is not row-block deletion.
- TabTransformer can learn numeric–categorical interactions in its final MLP. FT-Transformer admits numeric tokens into within-row attention; SAINT admits companion rows. Database foreign-key and temporal semantics do not arise from arbitrary batch membership.
- Existing worked attention examples use distinct, explicitly illustrative interventions: changing the companion key changes weights; holding weights fixed while changing its value changes the weighted contribution. They are not trained probabilities.
- Fixed-split seed uncertainty, dataset-level ranks, non-equivalence after a nonsignificant test, and the parameter/compute confound in adding a row block remain explicit. Added a prediction prompt before local score disclosure.
- Corrected malformed `sqrt`/double-escaped LaTeX and tensor captions that called arrays including H “per-head.” Expanded canonical `lessons/depth/0047.md` feeds lesson, notebook, and reference.

The model/training implementation did not need an algorithm repair. Tasks1–3 already train the student's live packing/attention/stage functions; Task4 is explicitly isolated from supervised training. Four live tasks retain nine blanks. The final notebook has 77 cells, 29 code cells, nine portable figures, and a runnable artifact/interpretation EXIT.
