Important source corrections:

- Default classification checkpoint: two features per group, width 192, six heads, FFN 768,12 layers, 10 classes, 7,244,554 parameters/81 tensors.
- The target token receives a class rank after context-mean imputation plus a missingness flag, not an unconditional all-zero placeholder. Missing flags use −2; value and flag inputs remain separate.
- Group identities are random 48-dimensional vectors passed through a learned 192-dimensional affine map; they are not semantic feature-name embeddings.
- Query row attention retains six query heads but reuses the first context key/value head. Context-to-context attention uses all heads. There is one MLP after the two attention sublayers, and all three use add-then-non-affine-normalize wiring.
- The historical CPU attention fallback computes its inverse-square-root scale as a float32 scalar even in float64 inference. Preserving this convention reduced full-model discrepancy from roughly 1e−7 to 1e−13.
- The default classifier averages class-aligned probabilities from four views. Its numeric recipe differs from the lab's explicitly simplified one-view recipe.
- The release's fingerprint is a salted row-byte hash with duplicate-training-row handling, whereas Methods describes a random normal identifier. Source outlier processing compresses tails instead of deleting rows.
- Original synthetic generator code was not released with the Nature checkpoint. The full 130-million-task training procedure is not reconstructed by downloading inference weights.
