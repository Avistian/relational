## Model/source repairs

The actual release is D=192, six heads, 12 alternating feature/row blocks and a 768-wide feed-forward sublayer. Numeric groups contain two features. Drift Time2Vec has one affine plus 99 sinusoidal coordinates, repeated in each group before a learned 102→192 projection. Base has a 2→192 projection; separately pretrained NoT2V has 3→192. The target token, feature-position vectors, nonaffine post-residual LayerNorm and complete 192→768→10 decoder are visible. Every tensor is loaded. Query row attention shares first-head context K/V across six query heads; context uses ordinary six-head attention.

Source behavior decides several non-obvious details. Constant-channel selection inspects all supplied rows despite training-set docstrings. Missing numeric means use the context; standardization is sample-based and adds 1e-6. Time min–max scaling uses context endpoints but clips to [−5,6], and a constant context range adds one to the denominator rather than forcing all future offsets to zero. A source comment incorrectly implies a separate time token; actual forward and checkpoint shape establish concatenation. The attention legacy fallback rounds the scalar through float32, while the active Torch 2.13 SDPA branch uses exact 1/sqrt(32).

Initial capped and rounded-scale pilots are preserved with exact operator copies in `labs/sources/l068-v2/`. Parent independent arithmetic identified the active-branch scale issue. ## Experiment and interpretation

The final all-row panel uses Electricity 1260×5, Parking 1294×4, Chess 533×9 and original Intersecting Blobs 1680×2. The paper's appendix has a binary/three-class wording inconsistency; the released task has three classes. Cutoff fractions .4/.55/.7 are floored to domain counts and paired with split seeds 0/1/2, baseline/drift checkpoints 1/2/3 and feature RNG seeds 17/18/19. NoT2V offers only checkpoint 1. Each source domain holds out 10% ID; all future rows are OOD. These are joint repetitions, not a split×initialization factorial design. The source's random 30–80% domain-and-sample eligibility and class-coverage retry selection are deliberately not claimed. Missing full-class ID AUC remains unavailable with its count.

All five arms use the same data, partitions, one raw numeric view, fp32 and temperature 1. The baseline-with-time control appends the clock as a numeric feature; baseline-without-time removes it. Source-selected `best_dist` and `best_base` preprocessing, 32-view inference, fingerprinting, outlier choices, fp16 and differing temperatures are outside this matched local comparison. Exact released **dataset preparation** is checked; exact optimized **inference preprocessing** is not claimed.

`_verify_l068_v2_results.json` contains 120 records / 37,995 predictions plus six live SCM diagnostics. The corrected full run took 156.83 CPU seconds. Strong synthetic behavior is visible: Blobs drift accuracy .9487 versus base-with-time .5961, while scalar-time NoT2V reaches .9908. Chess is negative evidence: drift accuracy .6762 versus base-with-time .7158, and drift log loss .7721 versus .7033. Electricity supplies a metric disagreement: drift accuracy .6616 versus .6456 but AUC .7467 versus .7492. Parking improves over the baseline, yet the zero-time intervention and NoT2V can outperform drift, preventing a blanket claim that the learned clock is always beneficial.

After within-dataset averaging, the three-real-dataset mean drift-minus-base-time log-loss gap is −.0276; the whole-dataset paired bootstrap 95% interval is [−.1476,.0688]. This tiny roster does not establish a general advantage. Exploratory Friedman p values are .9384 accuracy, .2805 AUC and .9702 log loss; no rank gap exceeds approximate Nemenyi CD 3.5215. The paper uses a different Wilcoxon-Holm analysis. Failure to reject does not establish equivalence. Drift's average confidence on the unweighted boundary grid is .685/.648/.669 across its three times: neither monotone confidence decay nor measured calibration follows.
