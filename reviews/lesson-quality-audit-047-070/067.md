Before: the generic foundation package explained retrieval versus fine-tuning, but only at about 900 words. It exposed a small generic task around an actual historical checkpoint experiment with six gradient updates and 24 test rows. That path bypassed the released local normalization recipe and could shortcut a one-class context to a constant predictor. It lacked a standalone full-model source/gradient/update comparison and a canonical scoped builder. It did not reconstruct the full paper budget, architecture explanation or live evidence dependencies.

This is a bounded local replication of the specified mechanism, not reproduction of the paper’s 95-task results.

## Scientific repairs and source discrepancies

1. Full backbone visible in notebook; five student functions feed actual inference/training. Historical operators and `_verify_l067_results.json` are unchanged.
2. Numeric local source path now pads first, forms contiguous T×B×100, uses masked sum/count and centered-square sample moments, then epsilon/clamp and division(F/100). Historical power/outlier/temperature wrapper is not substituted.
3. A provisional normalized B×N×F mean/std shortcut failed parent source reconstruction: on real diabetes duplicate/constant local features, cancellation changed one transformed value from 0 to 2.39909172 and probabilities by .00138575. The provisional run was stopped, source/results/logs preserved in `labs/data/cache/l067-provisional-normalization`, and the full panel restarted after correction. No old result was rehashed. New source fixture matches exactly; parent corrected smoke maximum probability delta 2.742e-6.
4. `pfn.normalize_data` finite-precision behavior is documented without presenting amplified constant values as desirable. The source has an epsilon-amplified float32 reduction sensitivity; mathematical isolation and bitwise batching independence are distinct statements.
5. Paper anchor exclusion implemented; released training retains the anchor. Source parity is conditional on the same supplied episodes, not equality of sampling distribution.
6. Final paper learning rate .01 and released CLI 1e-5 are separate predeclared diagnostic arms. Both receive identical episodes and initial weights. No per-dataset/test tuning selects the learning rate.
7. Output class axis comes from outer training labels. A local context or test batch with one class never shrinks K or triggers a constant-model shortcut.
8. Source hooks/instance overrides, actual model runtime settings, nested bytecode/global helpers and function-valued defaults are bound or rejected by identity checks. Parameters and buffers are independently hashed. Backward/pre-backward hooks and parameter gradient/postaccumulation hooks are rejected; final weights/runtime restore is asserted.
9. Each selected/final adapted state is saved to a unique ignored weight directory with recorded file checksum; public runner can recreate it. Source references never supply measured predictions for the teaching model.

Random-k is a label-blind without-replacement prefix; official vanilla helper uses class quotas and can sample with replacement. Global-all is an additional local control. Both controls share the corrected wrapper, not every historical official baseline implementation detail.

No categorical one-hot comparison, original TabZilla tenfold partitions, large tasks, longer early-stopping trajectory, tuned tree/deep baselines, global-context FT interaction arm, exact/shared trained ablation, new synthetic pretraining or paper GPU runtime reproduction. The small budget can reject all updates; that is valid local evidence, not a refutation of the paper.
