## Repaired implementation and evidence

Historical `labs/relkit/benchmark_core.py`, `labs/relkit/foundation_experiments.py:validation_audit` and `labs/_verify_l059_results.json` remain unchanged. The new behavioral check replays every one of the 1,000 historical rows through the live selector, correctly interpreting stored `seed` as index and actual RNG seed as 59+index. Historical labels are balanced in expectation, not forcibly balanced. No source hash was changed to relabel an old result.

The scoped module `labs/relkit/validation_audit_l059.py` defines a27-candidate fixed ARD grid: λ=.01/.1/1 and each η=.25/2/16; exact LOO mean PRESS; first-index ties; four label-blind outer folds;64 development rows and 4,096 fresh rows. No learned preprocessing or feature selection. Internal selection uses 48 rows, each LOO fit 47; outer refit 48. External selection uses 64 labels, but each outer coefficient fit still uses 48 rows. Each outer predictor is evaluated on the same fresh queries to give a matched target. Outer folds are averaged within each independent synthetic repetition.

New author evidence:

- `labs/_verify_l059_v2_results.json`:30 repetitions, seeds 5900–5929. External matched optimism .069269, t95[.022023,.116516]; internal .027346,[−.028857,.083549].
