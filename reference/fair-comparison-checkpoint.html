Fair model comparison

A compact audit before claiming a neural model beats trees.

Lesson 050 · Claim scope · Glossary

DecisionRule to freeze
PopulationDataset IDs, task definitions, positive class, source hashes and exclusions.
InformationSplit first. Fit every imputer, scale and encoding using training rows only.
SearchDeclare family-specific candidates, count or time budget, stopping criterion and tie rule.
SelectionValidation chooses the candidate and checkpoint. Test evaluates the frozen choice.
RepeatsRecord split seeds separately from training seeds. Save actual row IDs.
UncertaintyPair differences within each task; state what changes across repeats.
Across tasksAverage seeds first, then rank each task. N is datasets, not seed fits.
Paper boundaryMatch table, metric, model variant, preprocessing, split, tuning and aggregation.

Minimal arithmetic

Per-seed difference: δₛ=AUROC(FT-T)ₛ−AUROC(XGB)ₛ. Report δ̄, sample SD and, if useful, the conditional interval δ̄ ± t₀.₉₇₅,S−1 sδ/√S. At S=3, t≈4.303. This interval excludes uncertainty over other splits and populations.

Rank task means, with shared ranks for ties. Friedman applies to three or more arms; Nemenyi CD=qα√[k(k+1)/(6N)]. With k=N=3, CD≈1.914. For two families, an exact sign test across independent non-tied datasets is a useful small-N check: even 3–0 has two-sided p=0.25.

Claim template

“On [named tasks], under [split/preprocessing/search policy], A exceeded B on [count] tasks with [per-task differences]. Uncertainty covers [unit]. This does not establish [broader claim]. The paper comparison is [verdict] because [named protocol differences]. Next we will predeclare [experiment].”

Overlapping error bars do not prove a tie. A nonsignificant test does not prove equivalence. Equal trials do not guarantee equal compute. An ensemble metric is computed after combining predictions; it differs from averaging seed metrics. A close number with a mismatched protocol remains INCOMPARABLE.
