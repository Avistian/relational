Cluster-GCN: the batch is a graph

Partition eligible training nodes once. Shuffle clusters each epoch, combine q groups, and slice the original adjacency on their union. Reuse that node set at every hidden layer.

Three invariants

  1. Partitions are disjoint and cover all eligible nodes.
  2. Features, labels and both adjacency axes use the same local-to-global ID order.
  3. A[B,B] restores edges between selected clusters. Block-diagonal concatenation does not.

Compute and probability

Hidden-state array proxy: 4bLF bytes for b nodes, L hidden stages and F float32 coordinates. This excludes gradients, parameters, sparse structures and caches.

Sampling q of p clusters uniformly: conditional on one endpoint’s cluster being chosen, a crossing edge’s other cluster is selected with probability (q−1)/(p−1). This does not make nonlinear multi-layer gradients unbiased.

Evidence discipline

Equal epochs are not equal updates. Array estimates are not allocator peaks. A port with source checks is not historical numerical parity. Consult the reproduction contract and execution ledger before making a result claim.
