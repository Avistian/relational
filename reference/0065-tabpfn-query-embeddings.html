Measured evidence and limit

The native v2 predictor has lower seed-mean loss than the final-layer cross-fitted linear head on all three tasks here. The head remains a valid representation experiment; this result does not reproduce the paper's selected intermediate-layer and 29-task comparison. A clear failed gain is preferable to asserting the paper's outcome for a different protocol.

Before making a claim

  1. Identify source, model/checkpoint and data versions.
  2. Trace which labels enter each computation.
  3. State what is fixed, varied and measured.
  4. Use the right uncertainty and aggregation unit.
  5. Name the unrun comparison and a falsifying experiment.

Query-embedding information card¶

For row i in fold k: zᵢ=gθ(xᵢ;D outside fold k) with its query label hidden. Scatter zᵢ back to original row i, then train the head on (Z,y).

Choice Audit
Encoder role Own label absent from both context and query input
Fold assembly Exactly one embedding per original row ID
Layer Selected without test feedback
Head Training-fitted scaler and validation-selected regularization
Test context Declared fold-context averaging position

Frozen weights can still condition on labels through activations. Mean embeddings followed by a nonlinear probability link need not equal mean probabilities. A valid representation experiment can honestly fail to improve the native predictor.
