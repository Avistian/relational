LESSON 049

Two ways to control which features speak

DCNv2 made feature crosses explicit. ExcelFormer and Trompt ask a different question: how should a network route information among heterogeneous columns? Read them as two answers to that question. ExcelFormer constrains the direction of feature attention; Trompt repeatedly gathers feature values into learned prompt states. Only after those routes are clear can a benchmark tell us whether their extra structure helped.
