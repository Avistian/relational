Retrieve locally, then test adaptation

A computation and evidence reference

Core distinction

No, retrieval changes inputs; fine-tuning requires measured parameter updates.

Implementation contract

OperatorRequired behavior
nearest_contextReturn stable exact nearest row IDs; handle identity exclusion before selection.
local_episodeRetrieve around an excluded anchor, shuffle the neighborhood, and return disjoint context/query values, labels and IDs.

Measured evidence and limit

Exact retrieval alone does not uniformly improve the global v1 baseline. Six-step local fine-tuning changes the actual pretrained parameters and has the best mean rank in this three-task, 24-test-row-per-task panel. The small test sample and conditional seeds make this exploratory; no broad adaptation superiority follows.

Before making a claim

  1. Identify source, model/checkpoint and data versions.
  2. Trace which labels enter each computation.
  3. State what is fixed, varied and measured.
  4. Use the right uncertainty and aggregation unit.
  5. Name the unrun comparison and a falsifying experiment.

Primary reading: Retrieval & Fine-Tuning for In-Context Tabular Models. Exact regeneration contract.
