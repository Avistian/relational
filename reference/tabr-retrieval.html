TabR: retrieval contract

TabR-S: shared linear encoder → one learned retrieval module → residual addition → one residual predictor block → prediction head. No numerical embeddings or pretraining. Both training and inference retain access to a labeled training memory.

Three distinct boundaries

Keep validation/test labels out of memory. Exclude the exact training query ID. Match deployment availability, including delayed labels and entity/group restrictions. Feature equality alone does not identify the query. Context freeze fixes neighbor IDs; it does not freeze the model’s gradients.

Evidence language

Source parity checks a specified computation with copied weights. A fixed-budget local comparison estimates a different experiment from a tuned benchmark. Seed intervals condition on the split; rank tests use datasets as blocks. Permuting stored labels after training measures reliance on aligned labels, not performance after retraining without them.
