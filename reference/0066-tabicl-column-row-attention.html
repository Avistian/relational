Measured evidence and limit

With identical 60 query rows, mean log loss is 0.5586 at context 60 and 0.4245 at context 540. Mean prediction time rises from 0.792s to 1.962s. One task and three nested context draws do not establish the paper's large-data benchmark claim.

Before making a claim

  1. Identify source, model/checkpoint and data versions.
  2. Trace which labels enter each computation.
  3. State what is fixed, varied and measured.
  4. Use the right uncertainty and aggregation unit.
  5. Name the unrun comparison and a falsifying experiment.

TabICL three-stage card¶

Column: I reads U_context → M; all U read M → cell-conditioned W,B. Row: feature tokens and summary tokens → one row representation. Dataset: row representations plus context labels → query predictions.

For C=N=500,m=16, inducing score elements are mC+Nm=16,000 per column/head. Full 500×500 attention uses 250,000. Later row/dataset stages and projection costs remain.

Affine fixture: x=2, W=(0.5,−1), B=(0.1,0.3) gives (1.1,−1.7). W and B are context-conditioned. Positional feature information and permutation ensembling are not exact single-view permutation invariance.
