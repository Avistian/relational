Axial attention shape card¶

Stage View Sequence being mixed
Hidden table B×N×G×D Rows and token positions remain distinct
Feature attention BN×G×D Features/target within one row
Sample attention BG×N×D Context rows at one token position
Readout B×Q×D Query target-token states

N=C+Q; G=F+1 locally. Feature scores scale as N·G²; context-only sample scores as G·N·C per head. For N=100,C=80,G=11 these are 12,100 and 88,000. A permutation is required before merging the feature axis into the batch. Score counts are not peak-memory measurements.
