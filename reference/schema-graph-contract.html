One example, three answers

Customer 10 reaches product 10 through line (100,1), quantity 2, and line (100,2), quantity 3. Binary existence = 1; number of line paths = 2; quantity sum = 5. Select the operation that answers your question.

Validation order

  1. Validate the declared keys and values.
  2. Resolve each FK in sorted child-row order.
  3. Retain all nodes, including empty and isolated stores.
  4. Construct and check reverse stores.
  5. Compare full graph path tuples against SQL JOIN output.
  6. Compare SUM and LEFT JOIN counts independently.
  7. For prediction, add a separate temporal availability contract.

Vocabulary

Composite key
A tuple identifying a row; repeated components do not imply a duplicate tuple.
Role
The particular FK constraint, such as buyer or referrer.
Orphan
A present foreign-key value with no matching parent.
Bag multiplicity
How many contributing rows remain before explicit deduplication.

The converter supports the explicit integer-key schema, not every SQL dialect or arbitrary schema. The full 33-database audit is reproducible course evidence, not a model-paper result.
