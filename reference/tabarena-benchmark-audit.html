Before quoting a leaderboard

A leaderboard compares fitted procedures on a defined task population. Pin those choices before interpreting the order.

Computation card

Errors are lower-is-better: 1−AUC, log loss and RMSE. Released metric_error is already converted. Never mix their raw units across tasks.

rank(e) = 1 + count(errors < e) + (count(errors = e) − 1)/2
dataset rank = mean(split ranks)
benchmark rank = mean(dataset ranks)
pairwise win = 1 for lower error, ½ for tie, 0 for higher
Elo odds(A/B) = 10^((E_A − E_B)/400)
Elo p(A/B) = odds/(1 + odds)

Trace: errors [.4,.2,.2,.9] → ranks [3,1.5,1.5,4]. Four methods imply win totals 4−rank. A 400-point Elo gap → odds 10 → probability 10/11; this is not accuracy.

Paired dataset bootstrap: compute each dataset’s method-rank gap; sample whole datasets with replacement, retaining method pairing; average; repeat; use 2.5th/97.5th percentiles. Repeated outer folds are not independent datasets. Crossing zero does not establish equivalence.

Two different statistics: mean(split ranks) differs from rank(mean errors). L056’s main audit uses the former. Its supplementary Friedman/Nemenyi analysis uses one mean-error rank vector per dataset.
