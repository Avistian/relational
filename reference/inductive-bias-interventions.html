An inductive bias is a learning preference under limited evidence. A response to an intervention is evidence about the specified training procedure. It is not proof that a model family cannot represent the target.

Calculations to reconstruct from memory

Smoothing: d²=(xᵢ−xⱼ)ᵀC⁻¹(xᵢ−xⱼ); w=exp(−d²/(2h²)); pᵢ=Σwᵢⱼyⱼ/Σwᵢⱼ. Include self-weight. At h=0 return original y. The released classification function maps p>0.5 to 1, otherwise 0. C, feature selection and quantile transforms must be trained without held-out labels.

Rotation: RᵀR=I, so (XR)Rᵀ=X. For first-layer weights W, W′=WR gives (XR)(WR)ᵀ=XWᵀ. This is transported-weight equivalence. Independently initialized AdamW runs need not match.

Noise search: Gini impurity = 2p(1−p). Gain = parent impurity − weighted child impurity. The maximum training gain over more candidate splits cannot decrease. Trees can overfit noise. A width-H dense first layer adds H weights per additional input; count alone does not determine test error.

Readout and interpretation

Use paired effects: Δₛ=accuracy(changed, seed s)−accuracy(baseline, seed s). Report the mean, sample SD and a clearly labeled conditional seed interval. Repeat rotations, noise realizations, splits or tasks to study those sources of uncertainty; repeating only model seeds does not cover them.

Rank models within each dataset. The unit for cross-dataset inference is the dataset. A small Friedman p across a selectively chosen condition is not a universal winner certificate; account for exploratory multiplicity. A large p is not equivalence.
