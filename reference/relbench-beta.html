Metric¶

AP = sum(recall_increment * precision_at_threshold). Process all equal scores together. Labels[1,0,1,0,1], scores[.9,.5,.5,.1,.1] produce AP 1/3+2/9+1/5=.755556. Constant scores give prevalence. AP is neither ROC-AUC nor trapezoidal PR area. No positives: explicit 0 convention.
