GCN arithmetic

Add exactly one self-loop, then compute augmented degrees. S[i,j]=(A+I)[i,j]/√(d[i]d[j]); each layer is S H W. For path features [2,4,8], the middle output is 5.415816 with W=1. Remove node2 before normalizing and it becomes3. Label masking alone leaves the feature route intact.

Release details worth checking

Two bias-free layers, hidden width16, input/hidden dropout0.5, ReLU, Glorot weights, row-normalized features. Mean training cross-entropy plus0.0005×½‖W₀‖². Adam0.01; at most200 epochs. Stop after zero-based epoch10 when current regularized validation loss exceeds the previous-ten mean. Use last weights, not a restored best checkpoint.

Sampling checklist

Both edge endpoints must be eligible. An empty neighbor mean is zero, while the self branch remains. With64 roots and fanouts10,10, there are at most7104 node occurrences, not necessarily7104 unique nodes. The first transform is shared between roots and sampled neighbors. Our extension uses full-neighbor inference; it is not a Hamilton table reproduction.

Verdict ordering

  1. Incompatible protocol → INCOMPARABLE.
  2. Fewer than100 published-target initializations → INCOMPLETE.
  3. Compatible declared modern port, mean within±1 percentage point of81.5% → CLOSE.
  4. Outside the fixed tolerance → FAIL, then diagnose without tuning against test labels.

The course band is not a paper confidence interval. Modern reconstruction can be CLOSE while exact historical framework parity is INCOMPARABLE. Sample SD measures initialization variability on one split; SE=SD/√100 describes its mean, not future-dataset uncertainty.
