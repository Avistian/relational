An ensemble you can audit

All probabilities must describe the same class on the same rows.

Computation

Z: N × M OOF probabilities
w: M nonnegative weights, sum(w)=1
p = Z @ w
binary log loss = −mean[y log(p)+(1−y) log(1−p)]
candidate_j at step t = (previous_sum + Z[:,j]) / t
choose lowest OOF loss; allow replacement
retain best OOF prefix; weights = counts / prefix_length

Worked trace: selected [A,A,B,A] → counts [3,1] → weights [.75,.25]. Each member is evaluated once at inference. Identical copies add no prediction diversity. A best-prefix guarantee applies to OOF loss, not test loss.

Evidence boundaries

Report logloss(stack)−logloss(OOF-best): negative favors the stack. Pair seed differences before constructing intervals. Seeds describe fit variation under fixed data, not future population shift. Average seed errors per dataset before ranking; keep datasets as the statistical units. Weight is not causal usefulness: remove a family and reselect for an ablation. Fair cross/within-family comparisons also require matched budgets.
