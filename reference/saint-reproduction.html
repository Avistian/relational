Reference · Lesson 047

SAINT: mechanism and reproduction card

Row attention: pack [B,T,d] → [1,B,Td], attend over B rows, restore [B,T,d]. T includes CLS. Each head has B×B weights; a whole row is one sequence element. Do not substitute attention down each individual column.

Prediction contract: weights + fitted preprocessing + query + permitted companion rows + batch order/membership. Permuting the same batch reorders outputs; replacing companions can change outputs. No target labels enter the encoder. Availability of held-out features must match the evaluation setting.

Pretraining: CutMix raw features, then mixup embedded vectors. Contrastive positives pair a clean row with its own augmented view. Denoising reconstructs original features using categorical cross-entropy or numeric squared error. The supervised lab and Bank runner do not reproduce that full pretraining experiment.

Source identity and explicit choices

Paper v1, 2 June 2021 · released code, pinned commit · source hashes and audit.

Executable stage: LN(x)+F(LN(x)); numeric 1→100→d MLPs; GEGLU; no applied attention dropout. This differs from the PDF’s x+LN(F(x)) and numeric one-layer description. Bank split follows released .65/.15/.20 random assignment; the PDF’s .65/.15/.25 sums to 1.05. Bank checkpoint selection follows the released binary branch: validation accuracy every fifth epoch. Our category vocabulary uses training rows only.
