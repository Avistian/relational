HGT: trace a typed message

A meta-relation is one source-type/relation/target-type triple. A meta-path is a sequence of such triples.

Modern released operator

source = z_s + RTE(T_target − T_source +120)
q = Q[target_type](z_t)
k = K[source_type](source)
v = V[source_type](source)
score = dot(q, k @ W_attention[relation]) * prior / sqrt(head_width)
alpha = softmax(score over ALL incoming edges, per receiver/head)
message = v @ W_message[relation]
aggregate = concatenate_heads(sum_sources(alpha * message))
candidate = dropout(A[target_type](GELU(aggregate)))
out = LayerNorm(sigmoid(skip)*candidate + (1-sigmoid(skip))*z_t)

Q/K/V are distinct learned maps. Attention and message matrices serve different roles. RTE affects the source key and value, not the target query.

Remember the worked trace

Scores[0,ln2] give weights[1/3,2/3]. Values[2,6] give14/3. Doubling the second logit gives[.2,.8] and5.2. Normalizing separately by relation gives[1,1] and is a different model.

Sampling and evaluation

  • Budgets are separate by node type. Candidate probability is proportional to squared accumulated normalized degree.
  • Sampling depth and neural layer count are different controls.
  • Remove both target-label edge directions for seed papers.
  • Time encoding does not enforce causal feature/edge availability.
  • Release DCG method0 discounts ranks1 and2 equally. MRR scores only the first relevant field.

Evidence boundary

NN teaching results are not CS Table2 results. A universal NN field makes perfect MRR achievable by a training-frequency baseline. The2020 source,2023 release and printed paper differ. Full CS execution remains unrun; full-paper parity is NOT_ESTABLISHED.
