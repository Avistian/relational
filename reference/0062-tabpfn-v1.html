Five live operations¶

  • def normalize_context(x,n): — Return standardized N×F rows using context sample moments, epsilon 1e-6, and the source clamp. Reject fewer than two context rows.
  • def scale_pad(x,max_features=100): — Scale k active columns using the historical K/k convention, then append exact zeros to reach K. Reject k outside 1..K.
  • def attention_mix(q,k,v): — Return scaled dot-product attention for B×H×receivers×headwidth projections, with keys/values already restricted to context.
  • def postnorm_update(h,attention_output,block): — Use the provided block modules to perform attention add/norm, then GELU feed-forward add/norm.
  • def aggregate_views(logits,shifts,classes,temperature=.8): — Restrict to active classes, undo each cyclic label shift, average logits, temperature-scale, and softmax. Validate dimensions and positive temperature.

Historical v1 operator card¶

Context-only sample moments → constant-column removal → optional fitted power transform → two-pass outlier softening → K/k feature scaling and zero padding. A row token is feature projection plus a linear label projection for context; queries use features alone. Twelve postnorm GELU blocks with context-only keys/values → query head 512→1024→10. Restrict to observed classes, undo class rotations, average logits, divide by .8, softmax. Core query isolation and full-wrapper isolation are distinct checks. Frozen pretrained inference is not new prior fitting.
