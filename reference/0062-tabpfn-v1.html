Row-token PFN trace¶

Input: context X,y and unlabeled query X*. Encode rows → add context/unknown label representation → repeated context-only attention and feed-forward blocks → query states → class head.

Scores (0,ln 3) imply weights (¼,¾). Values (2,6) yield 5. Query sender columns are blocked; True means allowed in the local API. Residual paths preserve each query's own features.

Query isolation requires fixed preprocessing and deterministic evaluation as well as the mask. Report historical checkpoint identity, ensemble settings, class mapping and cold/context/warm timing separately. Reduced RowPFN checks do not certify the full historical architecture or benchmark.
