Lesson 053 · Glossary

RealMLP: recipe and evaluation boundaries

Default on a new task ≠ never tuned. Develop the recipe on meta-train datasets, freeze it, then evaluate on separate meta-test datasets. Within each task, fit weights on training rows, choose an epoch on validation, and score once on test.

Numeric TD-S forward pass

Train-fitted robust scale → smooth clip → learned coordinate scales → three NTP linear/activation stages → zero-initialized NTP head. Hidden width 256 in the published recipe; two logits for binary classification, one standardized target for regression. No retrieval or pretraining.

ComponentExact rule
Robust scaleSubtract training median. Multiply by 1/IQR; if IQR=0 use 2/range; if constant use 0.
Smooth clipz/√(1+z²/9), strictly within (−3,3) for finite z in exact arithmetic.
Feature scalesh=u⊙s; initialize s=1; scale learning rate ×6.
NTP linearhW/√dᵢₙ+b. Bias is outside the width scaling.
InitializationStandard normal hidden weights/biases; zero output weights/bias.
ActivationSELU for classification; Mish for regression, both non-parametric.
LossCross-entropy, label smoothing 0.1; regression MSE.
OptimizationAdam, β=(0.9,0.95), ε=1e−8, zero weight decay; no dropout.
RatesBase 0.04 classification / 0.07 regression; factors scale 6, weight 1, bias 0.1.
Schedule½[1−cos(2πlog₂(1+15t))], where t is optimizer-step progress.
SelectionTrain 256 epochs, batch 256; restore last best validation epoch. No patience stop.

TD-S omits full TD’s embeddings, parametric activations, data-dependent initialization, scheduled dropout/weight decay and regression output clipping. The lab additionally excludes categorical encoding.

Interpretation checks

State the search budget before saying “tuned.” Test error need not improve when validation error improves. A small feature scale is not a causal importance measure. A fresh row split does not undo dataset-level recipe development. A nonsignificant Friedman result is not proof of equivalence.

Local evidence: three TabR-release splits, row caps 1200/600/600, three seeds, numeric TD-S width64/64epochs, six XGB candidates. Mean ranks: TD-S 3.000, XGB-fixed 1.667, XGB-tuned 1.333; Friedman p=.09697, CD=1.91362. INCOMPARABLE to the paper benchmark. Larger California TD-S evidence is a single-task demonstration; see the contract for its measured numbers and limitations.

Primary sources: paper §2–3, Table A.1 and Appendix A.2; pinned standalone implementation. Our target scaling follows its training-only statistics, while the paper text describes train-plus-validation scaling.

Preprocessing is training-fitted. TD-S variant, width, optimizer groups and training duration must accompany any score. A strong default is a transfer result for a recipe, not proof that its architecture dominates every tuned alternative.
