From self-supervision to graph prediction¶

Use this map after cold retrieval. For each model ask: what is an example, what information can enter it, what is shared, where does the loss act, and what remains at inference?

71–74 · Learn and transfer a row representation¶

VIME predicts changes and values from a corrupted row. SCARF recognizes paired row views. SubTab combines incomplete column views. CARTE uses value–column pairs and relation-aware attention to accept varying schemas. The question changes from can we learn without labels? to does that learned computation transfer to this target?

75–78 · Turn records into a relational computation¶

PyTorch Frame separates train-fitted conversion from learned tokens and row readout. Table-specific encoders provide aligned node states. Foreign keys route messages; availability clocks restrict them. A ceiling certificate identifies information lost by a chosen summary. Message passing then makes the alternative computation explicit.

79–80 · Keep the baseline decision defensible¶

Specify the prediction contract, compare a credible baseline and a justified challenger, freeze selection and retain predictions. A new architecture must earn its cost. Model knowledge is useful when it changes a falsifiable experiment.

81–86 · Choose and implement a graph operator¶

MPNN separates message, reduction, update and readout. GCN fixes coefficients from graph degrees. GraphSAGE combines sampled-neighbor and self paths. GAT learns neighbor weights with per-receiver softmax. Over-smoothing examines what repeated mixing can erase. PyG turns these operations into explicit tensor routing without choosing your split policy for you.

87–90 · Change the target, preserve the contract¶

A link target is a pair, so the hidden edge cannot reveal itself through messages. SEAL turns a pair into an enclosing graph. GIN predicts at graph level and preserves multiset information with learned sum-based updates. Cluster-GCN changes which subgraph supports each training step. The checkpoint asks you to defend both the numerical operator and the scope of the measured result.

Vocabulary that must stay precise¶

Term Meaning in this sequence
Example The unit with a target: row, node, candidate pair, or graph
Encoder The function that produces a reusable representation
Projection head A training-space transform, often discarded after SSL
Readout The operation producing a row, node, pair, or graph output from states
Support Inputs and edges required to compute a prediction; not automatically supervised
Shared weights The same learned parameters reused across named nodes, views, or rounds
Inductive access A declared exclusion of held-out entities/graphs from training inputs
Transductive access Explicitly allowed use of an unlabeled evaluation feature graph
Reproduction A named source experiment with an audited data, model and selection protocol

Read a diagram from input to claim¶

  1. Identify the prediction unit and write its tensor shape.
  2. Follow every branch and label where weights are shared.
  3. Find the reducer and its axis; list what information it discards.
  4. Put a boundary around training-only heads, losses and labels.
  5. Trace the inference path without those training-only objects.
  6. State the experiment that could test the proposed benefit.

A local arithmetic trace, a measured teaching run, and a full paper reconstruction answer different questions. Consult each lesson's linked reproduction contract for its actual coverage; this map does not upgrade any evidence status. Ask the tutor to challenge one arrow you cannot explain.
