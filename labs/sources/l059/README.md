# Official GKM reference snapshot

Retrieved 2026-09-10 from the paper footnote 2 [GKM toolbox](http://theoval.cmp.uea.ac.uk/~gcc/projects/gkm/), using its linked `gkmtools.zip`. HTTPS fails certificate hostname verification; the original HTTP endpoint serves the toolbox. Exact archive and file SHA 256 hashes are in `../../_sources_l059_v2.json`. These are unchanged selected source files from that archive, retained with original copyright headers and GPLv 2-or-later notices; `GPL-2.0.txt` is the archive license.

Source headers identify August 2007 v1.00. This snapshot is not proof of the exact revision/settings used for every 2010 paper experiment. The local lesson implementation derives from the paper equations. `_source_check_l059_v2.py` checks a credited Python translation of the source Cholesky/Schur algebra. No native MATLAB/Octave execution or optimizer reproduction is claimed.

`GPL-2.0.txt` preserves the archive's original short license notice byte for byte. [COPYING](COPYING) contains the full GNU GPL version 2 text retrieved from https://www.gnu.org/licenses/old-licenses/gpl-2.0.txt. The upstream files permit version 2 or any later version.
