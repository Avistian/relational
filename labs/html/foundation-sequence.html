058 · Read a benchmark without inheriting its bias

LessonRead labRun in ColabDownload notebookReferenceReproduction instructionsMeasured resultsUpdated audit and subset results10,000-candidate results

What you will do: Parse means and SDs, rank the declared panel, bootstrap paired datasets, and select a tiny benchmark without seeing held-out method scores; compare 1,000 and 10,000 proposals.

  1. parse_talent: Return two aligned DataFrames (means, reported SDs). Preserve original row labels, reject duplicate IDs/headers and malformed nonmissing values. Recognize empty, dash, em dash, NA, N/A and nan+nan as missing. Strip Markdown emphasis and accept scientific notation and + or ± separators.
  2. rank_matrix: Return [datasets, methods] average-tie ranks starting at one, lower rank meaning better. Reject nonfinite, empty or non-2D inputs and require an explicit Boolean direction. This function must rank only the supplied columns.
  3. dataset_bootstrap: Return [2, methods] percentile bounds at .025 and .975 by averaging resampled whole dataset rows. Use a local default_rng(seed), validate finite nonempty 2D input and positive integer draws.
  4. select_tiny: Propose trials subsets of size unique rows using default_rng(seed).choice(..., replace=False); sort their indices. Minimize MAE between subset and full-column means, keeping the first minimum. Return indices, first_indices, seen_mae and best_so_far (one incumbent loss per proposal). Validate finite nonempty 2D input and positive integer size/trials; size cannot exceed row count.
  5. method_holdout: Validate a complete score matrix and a unique nonempty integer seen-index list with a nonempty complement. Rank seen columns by themselves, call select_tiny, then rank unseen columns independently. Return seen, unseen, selection, and random/selected dictionaries each containing seen_mae and unseen_mae.

Author-reference evidence: Frozen-result reanalysis: six methods on 300 tasks; a separate 276-task complete panel for tiny-benchmark selection. No new predictive-model fits.

059 · When validation becomes training

LessonRead labRun in ColabDownload notebookReferenceReproduction instructionsMeasured resultsNested KRR results1,000-repeat results

What you will do: Replay the noise control, implement analytic leave-one-out KRR and nested selection, and compare 30 versus 1,000 independent synthetic repetitions.

  1. choose_validation: Return the first index of the minimum finite loss. Reject empty, nonfinite and non-vector inputs.
  2. loo_residuals: Return the paper §2.1 residual vector using the augmented inverse diagonal. Validate finite aligned nonempty vectors and strictly positive diagonal entries.
  3. select_krr: Fit each declared configuration using krr_fit, compute mean squared live loo_residuals, choose with live choose_validation, and return (chosen_model, index, all_losses). Reject an empty list.
  4. nested_predictions: Return a length-n prediction array and per-fold trace. For each integer fold, call live select_krr on complement rows, predict held rows, and scatter in original order. Trace fields: fold, fit_ids, held_ids, selected, selection_mse. Validate target/fold lengths and at least two integer folds.
  5. paired_difference: Return n, mean, sd (ddof=1), mc_se, and t95 for left−right. Reject nonfinite, non-vector, mismatched or fewer-than-two observations. Use scipy.stats.t.ppf.

Author-reference evidence: Historical 200-repeat noise control plus new paper-equation KRR experiments: 30 and 1,000 repeated datasets, with matched fresh evaluation of nested and contaminated procedures.
